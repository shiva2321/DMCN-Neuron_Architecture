# Claim Ledger

Single source of truth for the **evidence level** of every claim in this project.
Rules are in `GEMINI.md` (§9 claim ladder, §10 reporting). `docs/BOARD.md` may not state a stronger level than this file; `rpn/tests/integrity/test_claim_ledger.py` checks it.

**Levels (lowest the evidence supports):**
`IMPLEMENTED` < `OBSERVED` < `REPRODUCED` < `CONTROLLED` < `GENERALIZES`; and `REFUTED`, `UNAUDITED`.

**Editing rules**
- Raising a row to `REPRODUCED` or above requires: results file, ≥20 seeds, null controls (GEMINI.md §5) and strong baselines (§7), linked in the *Evidence* column. The `Gate` column names the integrity tests that enforce it.
- A row may be lowered at any time. Never delete a `REFUTED` row; add a dated note instead.
- Rows marked with a `Gate` that is an `xfail(strict)` test: when the underlying problem is genuinely fixed the test starts passing, the suite fails with XPASS(strict), and you must remove the `xfail` marker **and** update this row in the same change.
- Changing this file or the integrity tests requires explicit approval from the user (see `rpn/tests/integrity/README.md`).
